# IT Hub — цирковой маршрут

Мобильный сайт Дня открытых дверей КИКТ ВВГУ с картой шатра, девятью станциями и QR-печатями.

Публичная сборка не содержит значения станционных QR-кодов. Проверка прохождения и финального билета выполняется сервером проекта.

Сайт подготовлен для GitHub Pages по адресу `https://mersisk.github.io/ithub/`.
